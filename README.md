# Green Gate — 60 s commercial (Blender project bundle)

Everything here is generated by script; there are no stock assets.

| File | What it is |
|---|---|
| `build_commercial.py` | Builds the whole film in Blender 4.5 / 5.x: 11 studio sets, 15 shots, cameras, lighting, phone-screen animation. `--render` renders frames, `--save x.blend` saves the scene. |
| `gg_lib.py` | Models and materials: phone, watch, perfume, earbuds case, sunglasses, candle, serum, lipstick, shipping box, paper bag, studio rigs. |
| `screens/` | The real greengatemarket.store web app captured on an iPhone-size screen (fed with sample listings, since the live catalogue is empty). Shown on the phone display. |
| `tex/` | Printed graphics: Green Gate packing tape, bag print, product labels, shipping label, watch dial. |
| `titles/` | On-screen text, composited in post so it can be changed without re-rendering. |
| `music.py` | Original soundtrack, synthesised and locked to the edit (every cut on a beat). |
| `finish.py` | ffmpeg: frames + titles + music into the final MP4. |
| `hdri/studio_small_09_2k.hdr` | Studio light probe for reflections (Poly Haven, CC0). |

## Change things

* Titles: edit `make_titles.js` (or replace the PNGs in `titles/`), then re-run only `finish.py`.
* Music: replace `music.wav` with a licensed track and re-run `finish.py`.
* Quality vs time: `--samples` and `--res` on `build_commercial.py` (the Colab notebook has presets).
