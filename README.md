# Green Gate — 60-second commercial (Blender)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/bavumile873-cyber/greengate-commercial/blob/main/GreenGate_Commercial_Colab.ipynb)

A 60-second commercial for [greengatemarket.store](https://greengatemarket.store), built entirely by script in
Blender 4.5 LTS and rendered with Cycles on a Colab GPU.

* `GreenGate_Commercial_Colab.ipynb` — open in Colab, choose a T4 GPU, Run all. Frames are kept in Google Drive so
  the render resumes after a disconnect; the finished MP4 downloads automatically.
* `greengate_bundle.zip` — the Blender project: scene builder, models and materials, real app screens, printed
  graphics, title cards, original soundtrack generator and ffmpeg finishing script. See the README inside.

Product listings shown on the phone are sample data (the live catalogue was empty when this was made).
Studio light probe: Poly Haven `studio_small_09` (CC0). Fonts: Inter, Cormorant Garamond, Libre Barcode 128 (OFL).
